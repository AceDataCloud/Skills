# ACE Music for Amp

```sh
amp skill add AceDataCloud/Skills/platforms/amp/skills/ace-music-by-acedatacloud
```

From a reviewed checkout, use `amp skill add ./platforms/amp/skills/ace-music-by-acedatacloud`. Start Amp with an `ACEDATACLOUD_API_TOKEN` from [Applications](https://platform.acedata.cloud/console/applications?utm_source=amp&utm_medium=referral&utm_campaign=evergreen&utm_content=acemusic_amp_key) and ask it to load this skill. Use `amp mcp doctor acemusic-ace` to check the connection and `acemusic_list_models` to inspect available models without creating a task.

Describe a song or supply a title, lyrics and style. The skill also supports uploading reference audio, covering one owned track or blending two. Inspect [current prices](https://platform.acedata.cloud/services/acemusic?utm_source=amp&utm_medium=referral&utm_campaign=evergreen&utm_content=acemusic_amp_price) before using a billable tool. Preserve the original task ID for lookup. [Chinese](README.zh-CN.md) · [Workflow](SKILL.md)
