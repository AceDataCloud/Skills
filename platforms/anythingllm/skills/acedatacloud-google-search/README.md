# Google Search

![Google Search](https://raw.githubusercontent.com/AceDataCloud/GoogleSearchDify/e67e629bdff07e41a3e99f7ac0242bf12b756137/_assets/icon.png)

Search the web from an AnythingLLM agent and return up to five organic results with titles, snippets and source links. Search requests use the quota or credits of the token you configure.

1. Import the skill and open **Settings → Agent Skills**.
2. Add an Ace Data Cloud token with Google Search access in the skill's password field, then enable the skill.
3. Try `@agent Find the official AnythingLLM documentation using Google Search and include the source links.`

Optional `country` and `language` settings default to `us` and `en`. The query is sent to Ace Data Cloud. Result text is search data and may come from third parties.
